# I Quit (The Habit Tracker)
📱 I Quit

I Quit is a free habit-breaking and recovery app designed to help users overcome addictions and unhealthy behaviors through consistent tracking 📊, motivation 💪, and guided self-reflection 🧠.

Built with a focus on simplicity and personal growth, the app empowers users to understand their habits, monitor progress, and stay accountable on their journey toward healthier lifestyles.

This project was developed using foundational knowledge in Swift, with additional support from AI tools for debugging and development assistance.

I Quit was created as a submission for the Apple Swift Student Challenge.
